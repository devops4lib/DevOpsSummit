### Session notes
[Notes google drive folder](https://drive.google.com/drive/folders/1JHeGIOnBi5ycN9JNZiadqV8jhjaXDtFI?usp=sharing)

At each session we will ask for a volunteer notetaker. During the session we will take notes on google docs to allow for collaborative notetaking. After each session the volunteer notetaker should submit a pull request to this github repository with the final version of the notes for that session.

### Session roles
* Facilitator:  Open each session, call on people to speak if discussions get lively, and try to help us hear from everyone.
* Notetaker: Take notes.
* Timekeeper: Let us know when we’ve reached/are reaching the end of our session time.
* Advocate for full participation in the session. Ask for clarification on acronyms, tooling names or other phrases so everyone understands the conversation. A gatekeeper should ask even if they personally know the answer. 

### Discussion starters for facilitators
* Define the space
* Articulate a problem statement
* "what do we do well?"
* "What would you like to improve"
* "What deliverables to shoot for"
* "List of use cases"
